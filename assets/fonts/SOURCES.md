# Self-hosted typefaces

Downloaded from the official Google Fonts CSS service and fonts.gstatic.com. Files include Latin and Latin Extended subsets, use WOFF2, and remain unmodified.

- Barlow Condensed: normal 800. License: barlowcondensed-OFL.txt.
- Inter: variable normal 400–800. License: inter-OFL.txt.
- IBM Plex Mono: normal 400 and 500. License: ibmplexmono-OFL.txt.

CSS query: https://fonts.googleapis.com/css2?family=Barlow+Condensed:wght@800&family=IBM+Plex+Mono:wght@400;500&family=Inter:wght@400..800&display=swap
